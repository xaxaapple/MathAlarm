# Будильник× (MathAlarm)

Обычный будильник, который выключается только после **5 примеров на умножение** (таблица 2–9).
К каждому примеру дано 7 готовых вариантов ответа: 1 верный и 6 неверных. Неверный ответ сразу меняет пример.
Звук и вибрация не прекращаются, пока не решены все 5 примеров. Работает поверх экрана блокировки.
Дизайн — необрутализм.

## Как получить APK через GitHub Actions

1. Создай репозиторий на GitHub и залей туда всё содержимое этой папки (включая скрытую `.github`).
2. Открой вкладку **Actions** → **Build APK** → **Run workflow** (или просто сделай push в `main`).
3. Когда сборка позеленеет, открой её и скачай артефакт **MathAlarm-apk** (внутри `MathAlarm.apk`).
4. Если создать тег `v1.0` (`git tag v1.0 && git push --tags`), APK ещё и появится в **Releases**.

APK подписан постоянным ключом из `app/mathalarm.keystore`, поэтому новые сборки ставятся поверх старых без удаления.

## Настройки на телефоне (важно для надёжности)

- Разреши уведомления и **полноэкранные уведомления** (Android 14+) — приложение само покажет подсказку.
- Отключи оптимизацию батареи для приложения (особенно Xiaomi, Huawei, Samsung, Realme, OnePlus): разреши автозапуск и работу в фоне.
- Кнопка **«ПРОВЕРИТЬ ЗВОНОК»** в редакторе запускает весь процесс сразу — проверь на своём телефоне до первого настоящего будильника.
